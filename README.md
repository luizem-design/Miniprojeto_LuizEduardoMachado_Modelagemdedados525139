# Análise Exploratória de Dados - Varejo

Este projeto realiza uma Análise Exploratória de Dados (AED) em uma base de registros de compras de um supermercado, com o objetivo de limpar, tratar e extrair insights operacionais.

**Ferramentas Utilizadas:**
* Python 3
* Pandas

**Etapas Realizadas:**
1. Carregamento e inspeção estrutural dos dados.
2. Identificação de nulos, duplicatas e inconsistências.
3. Limpeza de dados (remoção de colunas residuais, deduplicação e conversão de datas).
4. Geração de estatísticas descritivas (foco no núcleo familiar dos clientes).
5. Extração de padrões de agrupamento (produtos por gênero e top 5 categorias).
